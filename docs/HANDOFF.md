## 30 秒看懂做了什么
- **作品**:《青石巷》(项目名 新游戏)。4 到 6 分钟的网页实时体验。雨夜里一条等待拆迁、居民已搬走的老街;一台残破的测绘机器人靠墙坐着。按住,它唯一能用的机械眼卡顿着睁开;琥珀色的光照到哪里,哪里就回到过去——窗户亮着灯、招牌亮着店名、卷帘门升起、人们撑着伞走过;墙上的"拆"字和征收通知在光里消失。光束停在对面的照相馆,门口浮现一家人,咔嚓两次闪光;停在面馆,店里亮起暖光、门口冒出蒸汽。高潮是正对面那扇门:门廊灯亮起,一个只剩轮廓的孩子靠着门框,机器人的眼睛收成一条测绘用的水平激光线,刻度一年年往上,到"十一岁"就停了;门口空一拍,灯接触不良地熄灭。结尾:"刻度停在十一岁。灯灭了,门还是那么高。"一只猫一直蜷在机器人身边,睁眼时坐起来,结尾时走开。
- **看图**:`docs/snap-playthrough.jpg`(全程 16 帧)、`docs/snap-door-memory.png` 与 `docs/snap-door-marks.png`(高潮)、`docs/snap-eye-iris.png`(光圈)、`docs/snap-cat.png`(猫)、`docs/snap-micro-photo.png`(照相馆)。
- **听声音**:`docs/audio-preview.wav`(40 秒:现在的雨夜 → 睁眼、记忆淡入 → 光离开、记忆切断 → 闪电与雷)。

## 自己玩
```bash
cd ~/Games/新游戏 && npm run dev
```
用 Chrome 打开终端里显示的地址,戴耳机,点击开始。按住空格或鼠标让眼睛睁开(第一次会失败,再按住);移动鼠标看街道;让光停在正对面那扇门上。
想跳过开场:地址后加 `?phase=wait`。想看帧率:加 `?stats`。机器较弱时会自动降低内部分辨率;也可以加 `?q=low`。
