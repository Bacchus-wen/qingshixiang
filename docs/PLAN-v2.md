# 第二版:现在暗、记忆满街霓虹(2026-10-16 15:00 起,约 8.5 小时,截止约 23:30)

## 为什么重做
用户对比参考视频后说"效果不好"。Claude 的诊断:
1. 光太少、画面太黑:我们按"银盐黑白、个位数光源"做,很多帧几乎全黑。参考一(cybercity)的街上有上百个光源,湿地面映出彩色倒影。
2. 模型太粗:机器人和道具是脚本拼的简单几何体。参考二(waggles kestrel-k1)有上千个零件。
3. 街道密度不够:没有车流、货架、密集招牌。

## 新方向(用户已选)
- **故事和交互不变**:雨夜待拆老街、残破机器人、按住睁眼、光锥里回到过去、门框刻度停在十一岁。
- **现在**:暗,但看得清。零星残存的霓虹(坏掉、闪烁、缺笔画),远处城市的光污染,售货机、红绿灯黄闪。颜色压暗、偏冷,但不是纯黑白。曝光整体提高,任何一帧都要能读出空间。
- **记忆(光锥里)**:参考一那样的满街霓虹——中文招牌一层叠一层、店里灯火通明摆满货、车尾灯、撑伞的人群、湿地面彩色倒影。光束里的过去和外面的现在反差最大。
- **机器人**:换成 waggles 的 kestrel-k1(CC BY-NC 4.0,非商用可改编,须署名 thtbee_ 并链接 https://github.com/thtbee/waggles,注明改动)。做成残破版:缺一条前臂、外壳脱落露出内部、污渍和雨水、只有一只眼还能用。
