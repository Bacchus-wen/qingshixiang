共同点:
1. **先有目标画面**:参考图或生成的"梦想截图"。
2. **截图 → 独立的眼睛挑错 → 改**,循环很多次。
3. **满场的小动静**。
4. **调色、声音、镜头**这些"电影感"的东西占了大量时间。
5. 最后**公开过程**(提示词、参考图、源码),过程本身就是内容。

## 二、Dream Loop(最值得照搬的流程)

开源技能 github.com/achimala/dream-loop(1720 星,MIT):

1. **先生成"梦想版"目标图**,存成 `.dream-loop/target.png`。
   - 要求它是**真实的游戏内截图**,不是概念图、电影剧照或画作。
   - 已有作品时,把当前截图当输入,生成"改进版",不要另起炉灶。
2. **循环**:
   1. 实现。
   2. 自己检查。
   3. 截图。
   4. 把截图和目标图交给**每次全新上下文的独立评委**。
   5. 照评委意见全部改完,再回到第 3 步。
3. **评委的评分表**(满分 10):
   - 构图 0–3:机位、画框、各部分位置和大小。
   - 光 0–3:色调、曝光、阴影、对比、氛围、反光、辉光。
   - 材质 0–3:每个表面的纹理、粗糙度、透明、湿润;不许发块、像塑料、过于光滑或发假。
   - 细节 0–1:逐像素比对。
   - 要求:列出**全部差距**,每条都要能直接动手改("这棵树看着假"不算,要说清是哪里让它显假、怎么改);该推倒重做就直说。
4. **退出条件**:
   - 8 分以上、帧率达标:完成。
   - 两轮没涨一分,或同一问题连续被指出两次:**停止小修小补,从整体上重想**(资产不够好?位置全错?灯光要重做?机位不对?)。
   - 大改后仍然没涨:停下来问用户。
5. **3D 资产**:
   - 主要资产用图生 3D,它推荐 Tripo h3.1。
   - 输入图的做法:**把目标图交给生图模型,抠出那一件东西的干净图(纯色背景),再生成 3D**,这样和目标画面完全对得上。
   - 次选 Blender 建模,最后才是程序化。
   - 贴图、法线、天空盒都用生图,不要用程序噪声凑。

## 三、Chetan 的"提示词弧线"(Cozy creek,24 条人类消息浓缩成 14 步)

1. 导入地基:复用已有的水。
2. 让水当主角:先生成**至少五张**场景概念图,再用 Blender 加 three.js 搭。
3. 收窄范围。
4. 对齐材质:景深、光、阴影、树叶颜色、岩石纹理,加反照率和环境光遮蔽,同时保帧率。
5. 修小屋:**看正面、背面、侧面近景**,修墙块、缝隙、窗洞、闪烁的门框。
6. 把调节项露出来:水、太阳、月亮、高度、对比度做成界面开关,一个小"摄影棚"面板。
7. **整体对照参考**:机位、辉光、调色、法线、房子形状、远景。
8. 找回性能:"什么最吃帧?"做性能分析;同时加上树叶、草、花的风动。
9. 到 11 是场景本身(石渠、隧道、防止镜头钻到地下)。
12. 坐在门廊:加一个坐着看的视角,用**截图确认过的**夜间和金色光,加**f/2.1 的照相镜头**。
13. 配乐:配乐加更轻的流水声和清晨环境声。
14. 定稿夜景参数。

## 五、对照我们:差在哪里、怎么改

| 他们的做法 | 我们现在 | 要改成 |
|---|---|---|
| 每个关键画面先有"梦想截图"当目标 | 只有最早的两张参考图,还是"电影剧照"风格(正是 Dream Loop 说不要的);两幕新故事的关键画面没有目标图 | 给 6 个关键画面各生成一张目标截图:用我们当前的截图做输入图,生成"改进版"游戏内截图(要你批) |
| 截图 → 全新评委按固定评分表打分、列全部差距 → 改,一个画面循环很多次;两轮不涨就推倒重想 | 整个故事一轮一审,30–60 分钟一轮,评语开放式,九轮下来模型 5.5 分 | 按画面分开审,固定四项评分表,评委每次全新上下文(Codex 本来就看不到代码),6 个画面并行;两轮不涨就换大方向 |
| 资产从目标图里抠出来再图生 3D,和画面对得上 | 对街是照片,街上没有 Tripo 模型 | 从第二幕目标图里抠出摊位、桌凳、灯笼等 → Tripo 生成 → 摆进三维(要你批积分) |
| 满场小动静、会对人反应 | 灰尘、灯管闪、钟摆、电视;会动的东西少 | 风:挂历纸页、货签、街对面废墟上的塑料布;光束扫过时灰尘打旋、飞蛾追光;电线上停着的鸟;回忆里的面馆热气、电视闪光 |
| 照相镜头、景深、摄影棚光、调色、声音 | 有调色和声音,没有景深;近景不像产品照 | 第一幕光停住时的近景加 f/2 左右的浅景深,焦点落在那件模型上;主角模型加看不见的柔光板,让金属和玻璃有好看的反光 |
| 一个"摄影棚"面板,调光不用改代码 | 每改一次光都要改代码、截图 | 开发模式加调节面板:光、调色、景深、光束,调好再写回代码 |
| 公开过程,过程就是内容 | 结尾只有一行字 | 结尾的"怎么做出来的":每件东西的原图 → Tripo 模型 → 在店里的位置,能点开转着看 |
| 按实际姿势生成模型 | 工作台台沿发软,机器人手和工具挤成一团 | 只对主角近景会看到的几件重新生成(要你批积分) |

## 六、执行顺序

**第一段:不花钱,约 3–4 小时**
1. 搭好我们自己的"梦想循环":
   - 定 6 个关键画面(第一幕货架近景、工作台收音机、转身、第二幕街景、整街亮起、结尾)和固定机位。
   - 一条命令截齐 6 张,并行派 6 个全新的 Codex 评委,汇总分数表。
2. 开发用的调节面板。
3. 第一幕近景景深、主角柔光板、几处风动和会对光束起反应的小东西。
4. 结尾"怎么做出来的"展示。

**第二段:要你批,和第一段并行**
1. 6 个关键画面的目标截图。走素材中台,会先把模型、参数、提示词给你看。
2. 第二幕街上的 Tripo 摊位等模型,从目标图里抠图后生成。
3. 主角近景瑕疵的几件重新生成;光照到时"变回崭新"的重新贴图。
