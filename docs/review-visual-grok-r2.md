我先读方向文档和这几张截图，再按摄影指导和美术总监的标准给第二意见。只看，不改文件。文档和方向我对过了。试玩表末格有一块纯绿，我先核对它是画面内容还是拼图空格，再写意见。亮度数据对得上。我再裁几块局部，确认人影、球体和光斑边缘，避免把描述写成事实。银盐的方向已经立住。绝境还差一口气：街是空的，人撤走的痕迹还没留下；琥珀色对了，光斑仍是一盏干净的灯。

**打动人的三处**

1. `snap-0345-street` 街心。雾吞掉远路，只剩一盏路灯，雨落在积水上，地平线压得很低，最像一张接触印相。中段实测停在中灰（约 RGB 90），黑压不下去，所以动人，也发灰。
2. `snap-0430-eye` 上三分之一压得很暗，机器人很小，贴着路缘，一条腿摊在水边。琥珀从它身上出去，雨进了光才变暖。
3. `snap-memory-windows` 右半边是实黑，窗只在斜光束里亮。`snap-memory-street` 收光最好：约六成画面是黑，暖色停在圆斑里。

**出戏的五处**

1. `snap-memory-street` 轿车四周的圆头细棍人。光是对的，人是占位的。
2. 同图中央边缘整齐的圆。试玩表眼睛特写之后的五格，几乎同一只圆斑、同一机位。
3. `snap-memory-windows` 左下角一颗棋盘格低模球，亮到裁切，下半幅亮度掉不下去。光束上沿是直尺。
4. `snap-0430-beam` 下半幅。光没有头，从中线灌到前景；井盖圆环等距；中间一只白盒子配一只黑球。
5. 试玩表第五格。白壳干净，机械眼几乎不发光，竖杆挡在镜片前，片边字被裁掉。各图的雨仍是同样粗的竖线，`0345` 街心还有一只白方块。

**和三部参考**

现在时已经是自己的签名：单色、低地平线、灯是个位数。Cloudpunk 的体素楼谷、NEON KAIDO 一街同时亮的品红青琥珀、Kestrel 的转台和仪表，这些帧里对不上。

还像的有两处。记忆里的砖墙、卷帘、电线、暖积水和那辆车，是 KAIDO 的夜街把灯灭掉一档。第五格的白壳特写，离 Kestrel 的产品手部只差一层油和一道刮痕。

**八条，省力的在前**

1. 把现在压回近黑。雾只留路灯到纸白那一条，暗部微冷，高光微暖。先收 `0345` 中段的灰。
2. 聚光贴一张脏投影：银斑、缺边、轻微重影。圆边一破，光就回到显影失败。
3. 雨只在光里亮，两三种粗细和速度，近处要虚。阴影里的雨几乎看不见。
4. 拿掉棍形人。留一件用过的东西：门框身高刻痕、一颗测量钉、车旁一只鞋。
5. 棋盘球、白盒子、黑球、街心白方块收成熄掉的灯，曝光钳住。井盖缺一个，加一道裂缝和一摊不成像的水。
6. 记忆镜头改贴地长焦，横移几厘米，焦点从眼睛走到第一件被照亮的东西。片边帧号留在安全框里。光只停在一件东西上，喘一口气，灭回银盐。
7. 特写里眼睛必须是光源：镜片上一点琥珀，外壳加刮痕和油膜。机器人半沉进水里，一块盖板垂着，另一只眼是死的。
8. 现在几乎不配乐。路灯接触不良的电流，近处只打在一种材料上的雨，远处滴水把间隔拉长。睁眼先一声快门，琥珀色用两三秒才起来；光锥离开，屋子的底噪立刻断掉。
