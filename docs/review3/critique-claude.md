# review3 批判(Claude,美术指导/摄影视角)

一句话:现在的画面读起来像"灰盒关卡加了雨和后期"。目标图靠**层次分明的光、每一米都有东西、能讲故事的材质**撑起来,这三样我们都没有。
实测亮度(ffmpeg signalstats,已换算成 0–255 全范围):now-street 90% 分位只有约 51,目标 present 是 70,说明暗部是一片死黑,不是"有东西的暗";past-street 10% 分位约 37,目标 memory 是 4,说明记忆态黑位整个被抬起来,画面发灰发雾。

## 1. 逐张问题(按严重程度排序)

### now-street.png(现在态)
1. **两侧立面是黑洞,看不出任何形体。** 目标里立面虽暗,但防盗窗、空调外机、晾衣、亮着的暖色窗、湿墙污渍都能读出来。改法:加一层冷蓝环境补光(半球光或光照探针,强度约为主光的 0.1–0.15);立面 8–15% 的窗户做 2700K 暖色自发光(按窗随机,有几扇闪);在右侧加一盏钠灯路灯作为主光,用聚光灯打亮右侧墙面和地面,并在灯锥里加体积雾。
2. **路面是一大块米色雾斑,近处是平滑的黑镜子。** 改法:删掉/压低路面中段那层均匀的加法雾;粗糙度用积水遮罩(积水区 0.05、干处 0.55–0.7)加裂缝/骨料法线;加井盖、雨水箅子贴花;倒影沿竖直方向拉长,而且只出现在积水区。
3. **没有讲故事的道具,"拆迁"没交代。** 目标里有卷帘门上画圈的"拆"、三轮车、自行车、塑料凳、滴水的雨棚、成团的电线、电线杆和变压器。我们只有几只纸箱和看不清的车。改法:卷帘门加"拆"字贴花,每侧至少 2 处;跨街电线做成每跨 10–30 根、垂度各不相同的线束;近景加三轮车或自行车作为前景遮挡。
(次要:远处楼是没有窗的灰色板子,天空是一条平的藏蓝;整体偏紫,和目标的"钠灯琥珀 + 冷蓝 + 一两种霓虹"差得很远。)

### past-street.png(记忆态,整条街亮)
1. **整幅发灰:黑位抬高、对比低、像蒙了一层雾。** 改法:全局雾改成按高度衰减,街面以上 3m 很快变稀;把泛光阈值调到 1.0 以上(只让招牌和灯芯泛光);色调映射用 AgX 或 ACES,并把黑点压到 0;调色时暗部压低 30–40%。
2. **招牌是浮着的发光平板,上面的字是乱码("招?所"之类)。** 目标里招牌有金属边框和灯箱厚度,霓虹灯管有描边,文字是真的且能读(粥粉面、旅社、卡拉OK、萬記、日用百貨)。改法:招牌做成有厚度的盒子,加支架;用真实中文店名配合适字体渲染贴图;亮度分层次,每个画面只让 1 块主招牌最亮,其余低 1–2 档。
3. **记忆里的街是空的,没有生活。** 目标有打伞的人群、开着大灯的老轿车、亮着暖光、堆满货的店内。我们的店面是黑的,墙上还是西式嘻哈涂鸦,这在老中国街道上是错的文化符号。改法:店面用室内映射(interior mapping)的立方体贴图做暖光货架;加打伞的人形剪影(实例化,简单走动);车开大灯;涂鸦换成"拆"、办证电话、手写小广告。

### past-low.png
1. **地面占了下半幅,是一张颗粒很重的塑料反光片,倒影是彩虹色竖条糊在一起。** 改法:加雨滴涟漪的环形法线(按时间随机);积水和干地的粗糙度要形成对比;颗粒和噪声在地面上降一半;倒影亮度乘 0.6。
2. **满屏绿、青、品红一样亮,正好是 AGENTS.md 禁止的"满屏霓虹赛博"。** 目标 memory 的底色是钨丝灯的暖琥珀,霓虹只是点缀。改法:店内暖光做主光,霓虹限制在 2–3 种颜色,强度设上限;绿色饱和度降 30%。
3. **中景的东西读不出来**(左边一个灰色人偶,一把伞,车是黑块),而且全都没有接触阴影。改法:中景物体加接触阴影/AO;车加灯;人偶要么打光讲清楚,要么删掉。

### past-high.png
1. **高机位把布景露了底:楼是薄片,屋顶是空的,整条街像玩具沙盘。** 改法:删掉这个机位;如果要保留,就给屋顶加水箱、天线、铁皮棚、太阳能热水器,并加大远处的空气透视雾。
2. **右侧三分之一是看不出东西的暗墙,镜头前还有粗大的粉色雨线,像划痕。** 改法:离镜头 1.5m 以内的雨滴压暗或剔除;重新构图,不要让大面积无信息的墙占画面。
3. **整条街只有一根电线,招牌朝向单调。** 改法:用线束替换单根电线;部分招牌改成垂直于街道伸出(目标图里竖招牌伸到街心上方)。

### robot-wide.png
1. **机器人太小(约占画面高的 8%),缩在画面后部中间,姿态像撞击测试假人,而且悬空,没有接触阴影。** 改法:按 robot.jpg 重新构图(见第 3 节);身下加 AO 和接触阴影;身下地面做湿暗处理;猫要放在画面里能看清的位置。
2. **整幅只有一盏品红灯,没有主光、补光、轮廓光的分工,机器人和墙糊在一起。** 改法:三灯布光——右上方暖色路灯作主光,背景街道方向的青色轮廓光,品红只作为溢出的点缀;眼睛必须是全场最亮的点。
3. **左前景是一块不知道是什么的黑形状,下半幅是空的暗水,背景是一面平的涂鸦墙。** 改法:前景物体要么给轮廓光,要么删掉;背景换成往远处延伸的街道,带焦外光斑和车尾灯(robot.jpg 的右半幅)。

### robot-close.png
1. **材质像干净的白色塑料/石膏人台,脏污像后来涂上去的棕色斑。** 目标是白色瓷漆崩落、露出深色金属,边缘渗锈,表面挂着水珠。改法:分层材质——基础白漆 albedo 从约 0.8 降到 0.55;用曲率加 AO 生成边缘磨损遮罩,磨损处露出深色钢(metalness 1,roughness 0.35);凹处做锈;顶面加水珠法线加 roughness 0.1;竖直方向加雨水流痕。
2. **结构太单薄:大平板拼接,胸口破洞里是空的黑,头是通用人台头,眼睛像侧面贴了一个环。** 改法:面板接缝做倒角,加深色缝线;胸腔和颈部用 Tripo 按部件生成活塞、线束、青色软管(参照 robot.jpg);眼睛做成嵌进头部的镜筒结构。
3. **背景是平的紫色卷帘门加巨大涂鸦,没有纵深,也看不到雨。** 改法:机位转到背景是街道的方向,让真实的灯在背景里形成焦外光斑;加逆光雨线;头盔上加流淌的水滴(动画法线)。

## 3. 构图与镜头
- **开场 street-eye(1.55m、fov 42、正中一点透视)**:太对称,像走廊。照 present.jpg 改:机位降到约 1.2m,靠左侧人行道;左立面占画面 40%;灭点放在画面右侧约 65% 处;路灯放右上角作为主光;左前景 2–3m 处放三轮车或自行车作为遮挡;fov 改为 48–50。参考坐标 pos(-2.8, 1.2, 8),look(1.5, 2.2, -40)。
- **street-low(0.25m)**:太低,地面吃掉半幅。抬到 0.5–0.7m,地平线放在画面高度约 45%;前景放一个清晰的积水倒影和一个合焦的道具(凳子或井盖)。
- **street-high(9m)**:删掉。结尾升镜如果要用,改成长焦(fov ≤ 35),加浓雾,并先把屋顶布置好。
- **robot-wide**:照 robot.jpg 改:机位高 0.5m,离机器人约 1.8m,从街道一侧看四分之三正面;机器人放左三分线,卷帘门作为左侧向远处延伸的墙;右边三分之二是往远处去的湿街、霓虹光斑和车尾灯;fov 约 40;腿伸向画面右下,让猫靠着大腿清楚入画。
- **眼睛特写(eye-hero / waking)**:构图可以保留,但背景必须是街道方向(要有焦外光斑),不能是平墙;加轮廓光,镜片上加水滴。
- **look(过肩记忆镜头)**:现在 `cam.pos.y = eyePos.y + 0.7`(director.js),头盔被推到画外,前景层丢了。照 memory.jpg 改:相机和眼睛基本同高(+0.1),往后 0.6m,往侧面 0.35m;头盔占画面左侧约 30%,暗、湿、有高光;眼睛在画面约 (23%, 25%) 处;光束斜着打向画面右下;灭点在画面约 42% 处;fov 50。
- **past-street 和 past-low 这种"整条街都是过去"的镜头**:不应该作为正片镜头出现。如果 fade 段的"最后一口气"需要它,也要保留头盔前景和光束边界,让观众始终知道"这是机器人眼里的画面"。
