2. **对街冷白路灯缺席。**图中没有清晰可辨的亮灯及对应受光区，最关键的结尾信息未成立。将灯杆、灯头放进机器人朝向的街道区域；灯芯亮而不糊，照亮局部墙面和路面，并给机器人外侧一圈克制的冷色轮廓光。

3. **前景曝光压死。**机器人背面、右侧工作台、左下物件连成黑块，无法展示 Tripo 网格质量。增加来自街面的低强度反弹光，分别读出金属外壳、关节、木台；保持眼灯熄灭，避免靠整体抬黑把废墟也照平。

4. **视觉重心落在中央废墟。**瓦砾与窗墙占据大半画面，机器人像被裁掉的陪衬。机位略后退并重新取景，让中央坍塌处服务于机器人视线；压低废墟细碎明暗对比，建立“机器人—路灯—空街”的观看顺序。

5. **店内身份不成立。**顶部粗黑横梁与两侧暗边只形成洞口，难辨家电修理铺。保留一小段可读的工作台，摆出轮廓明确的旧收音机、工具或拆开的电器，用弱环境光交代其厚度和接触阴影。

6. **机器人表面缺少材质区分。**头顶橙褐色污迹近似整片覆盖，背面近黑，下方银灰部件显得揉皱粘连。将油漆、裸金属、锈蚀分开控制粗糙度；锈集中于接缝和积水边，关节之间留出能辨认的暗缝。

8. **街沿与边缘细节生硬。**对街脚下数段纯黑直条像独立色块，需补出路缘石侧面、厚度和接地阴影；左侧自行车被切成碎片轮廓，调整裁切或摆位。窗框、电线、瓦砾远处偏糊，需检查纹理过滤与抗锯齿。闪烁、实际穿插无法由本张静帧确认。
