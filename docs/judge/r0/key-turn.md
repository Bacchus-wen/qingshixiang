2. **“从门口转身”没有空间依据。**当前俯视角主要展示头顶和地板，看不到门槛、门框或明确的朝外方向。改到门外略偏一侧、接近机器人胸口高度，以少量门框作前景；身体朝门，头略偏向街对面声源，避免正面僵坐。

3. **主角轮廓与背景粘连。**左肩贴着工作台亮边，左臂混入抽屉，右臂及旁边机器连成一团。横移机位或凳子，让头肩落在简洁暗背景上；移开右侧机器，双臂外缘留出可辨认的空隙。

4. **亮度中心被左上台灯抢走。**灯罩下数块黄白亮斑比镜头更刺眼，左侧雾光又冲淡轮廓。降低灯泡及桌面亮斑强度、收紧辉光；主角面部最亮，工作台退为次级亮区。

5. **机器人有纹理，却缺少统一的体积照明。**胸腹、手部和关节偏灰黑，细碎锈迹比大形体更突出。用门外斜入的宽暖光塑造头、胸、腿的明暗面，再以弱冷色环境光托起暗部，保留接触阴影。
