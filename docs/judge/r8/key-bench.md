r8 与 r7 肉眼未见足以改变评分的改善，主要问题仍在。旧物氛围成立，但还没达到靠画面证明 Tripo 模型表现力的水平。

1. **眼光唤醒收音机的因果不成立。**右侧眼睛是白点，左侧夕阳却照亮整台收音机；观众会归因于窗光。重做光源主次：压低左侧直射和散射，让眼睛朝内部元件投光，形成可辨认的局部亮区；光束只需轻微可见，避免变成激光。

2. **“自己的”没有视觉证据。**机器人直立在旁，既没操作，也缺少共同使用痕迹。让它低头前倾，一只手停在旋钮或待接线路旁；机壳和机器人安排同款手写编号或修补标记。仅靠朝向不足以表达归属。

3. **台灯遮住核心展示区。**左中灯罩横切开盖内部，挡住元件，暗色灯臂又割裂收音机轮廓。整灯移至左后方，灯罩退出开口；保证线路、扬声器背面和机壳厚度连续可读。

4. **台钳占据互动通道。**中央台钳把机器人手臂与收音机隔开，像机器人正在操作台钳。移到工作台远端；机位略升并向左调整，让眼睛、手、维修点形成清楚的三角关系，减少底部无效桌面。

5. **曝光两端损失结构。**左上黄白雾抹掉货架层次，右下胸腹和手部陷入黑团。降低雾与辉光，以宽而弱的反射光补出关节；让收音机内部成为亮度中心，桌面退一级。

6. **材质被统一锈色吞没。**机器人头壳密集竖纹像木头，桌面则像粗石板，灯臂、台钳也偏同一种褐色。头壳保留完整漆面，锈集中接缝；桌面恢复顺木纹，台钳钳口露出磨亮钢面，分别调整粗糙度。

7. **机器人肩肘仍显融化粘连。**右侧圆肩、软管、手臂轮廓纠缠。先调整姿态拉开空隙并补光；若原网格已融合，必须修网格或重新生成，增加锈纹无效。

8. **近景细节经不起看。**下方零件盒里的黑斑缺少厚度；黄色工具柄过于干净、棱边生硬。分开零件并明确接触阴影，工具补倒角和局部磨损；桌沿降低均匀碎裂噪声。

9. **画框及背景残留干扰。**顶部钟和招牌被随意截断，右上蓝竖线像辅助线。重新取景明确保留或舍弃；若蓝线是电线，补厚度、固定点和垂坠，否则移除。
