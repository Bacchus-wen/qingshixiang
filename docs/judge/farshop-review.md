# 对街"新興電器"做成三维:Codex 三轮评审记录(2026-10-22)

用户 10-21 选了"对街关键店铺做成三维"(历次评委都说对街像一张巨幅照片,比三维主角还精彩)。这一步不花积分、不生成新图或新模型,全部用已有素材:照片、修理铺里已有的 Tripo 模型。代码在 `src/systems/shop/farshop.js`。

做法:
- 照片里这家店的橱窗被挖空,后面是一间真正的三维小店:墙体厚度、两根日光灯、货架、录像带柜台。
- 货架和柜台上是修理铺里已有的 Tripo 模型(电视、录音机、收音机、风扇,三十多件)。电视屏幕在光束里亮起;橱窗里那台大电视放照片里那台电视的原画面。
- 现在态是照片里的卷帘门,和原来一模一样;光束照到的像素才露出后面的店。
- 招牌是立体灯箱,门口有台阶。
- 橱窗前的一家三口按照片手工描了轮廓,站在路沿上,脚下有接触阴影,只在从前态出现。
- 自带光照:按两根日光灯算明暗,光束正中最亮,和照片的规则一致,不加新灯。每帧多约 12.5 万个三角面。
- 路沿碎砖只属于现在:光束里和照片一样消失(整条街)。
