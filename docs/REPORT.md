## 怎么运行
```bash
cd ~/Games/新游戏
npm run dev                         # 浏览器打开显示的地址,点一下画面后按住空格
node tools/play.mjs --speed 4       # 自动试玩并截图,结果在 renders/play-sheet.jpg
node tools/shot.mjs memory-street   # 单个镜头截图
```
调试参数:`?phase=wait`(跳过开场)、`?speed=4`(加速)、`?power=0.2`(电量少,快速看结尾)、`?pfx=nossr,notraa`、`?skip=rain`。
