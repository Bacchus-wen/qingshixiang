## 当前状态(04:26)
**完整体验可以从头玩到尾,约 4 到 6 分钟。** 一张总览图:`docs/snap-playthrough.jpg`(自动试玩 16 帧)。
1. 黑屏"请戴上耳机 · 点击画面开始",只有雨声。
2. 镜头沿银盐质感的雨夜窄巷缓缓推进,停在暗处一台靠墙瘫坐的残破机器人前。偶尔有闪电照亮整条街,几秒后雷声。
3. 片边出现"按住"。第一次按住一定失败(眼睛闪一下就灭),提示变成"再按住";再按住,镜头切到它发光的镜筒眼,光圈叶片卡顿着打开。
4. 镜头到它肩后,移动鼠标让它迟钝地转头。琥珀色光束扫过的地方显出过去:窗户亮着灯、招牌亮着店名(张记面馆、光明照相……)、卷帘门升起、行人的轮廓撑着伞走过。光锥外依然是黑白的废墟。景深焦点会慢慢落到光照到的东西上。
5. **高潮**:它的目光默认就落在对面那扇门上。光束在门上停留几秒,它会自己接管——眼睛收成一条测绘用的水平激光线,门廊灯亮起,一个背书包的孩子靠着门框站着;刻度一道道亮起("小宁 五岁""六岁"……),孩子一年年长高,街上的人影都退去。刻度到"十一岁"就停了,孩子消失,门廊灯熄灭。截图:`docs/snap-door-memory.png`。
6. 孩子消失后空一拍:门口没人,灯还亮着,"十一岁"还在;然后门廊灯接触不良地闪几下,灭了。之后电量很快耗尽,光束闪烁、熄灭,镜头升起后退,完全黑下来后停一拍,出现两行字(Grok 写的):
   **刻度停在十一岁。 / 灯灭了,门还是那么高。**  字幕出现几秒后可点击重看。

## 怎么运行
```bash
cd ~/Games/新游戏
npm run dev                         # 浏览器打开显示的地址,点一下画面后按住空格
node tools/play.mjs --speed 4       # 自动试玩并截图,结果在 renders/play-sheet.jpg
node tools/shot.mjs memory-street   # 单个镜头截图
```
调试参数:`?phase=wait`(跳过开场)、`?speed=4`(加速)、`?power=0.2`(电量少,快速看结尾)、`?pfx=nossr,notraa`、`?skip=rain`。
