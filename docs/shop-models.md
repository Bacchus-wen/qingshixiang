## 流程(每件)
参考图(vmc gpt-image-2.5-sunburst max,浅灰背景产品渲染)→ Tripo(先做方法对比,定方法)→ `tools/blender/render_views.py` 渲染四个角度、与参考图并排 → 苛刻的视觉代理打分挑问题 → 改(换参考图 / 重做贴图 / 重做几何 / 拆件再组合)→ 减面与贴图压缩 → 进场景摆放 → 贴地检查 + 近景截图。
