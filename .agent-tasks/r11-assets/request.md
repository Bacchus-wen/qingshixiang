# r11:找可直接下载的免费高质量 3D 模型(只读调研)

项目要从"脚本拼的简单几何体"升级到接近参考视频(reference/x-cyber.mp4:东京风雨夜街,车、售货机、货架、电线密集)的精度。
场景:中国南方老街,雨夜,待拆迁。非商用。浏览器实时渲染,单个模型最好 ≤ 3MB(glb),总量 ≤ 15MB。

请找**不用登录、curl 就能下载**的模型,许可只能是 CC0 或 CC BY(写清署名要求)。优先顺序:
1. 车:老式轿车、面包车/小货车、出租车、三轮车或电动车(2–4 种)
2. 街道道具:自动售货机、红绿灯、空调外机、电表箱、垃圾桶、塑料椅、路障、自行车、晾衣架、灯箱招牌
3. 店铺内部:货架、冰柜、纸箱、瓶罐(可以是一整包)
4. 可选:老式居民楼外立面模块、防盗窗、雨棚

来源可考虑 Poly Haven(models)、Kenney、Quaternius、ambientCG、Smithsonian 3D(CC0)、GitHub 上的 glb 资源包、Sketchfab 中**有直链**的(多数需登录,则跳过)。风格要写实或半写实,不要卡通低模(Kenney/Quaternius 只有在没有更好选择时才列)。

每条写:名称、页面、直接下载链接(用 curl -I 核对过能下载)、格式和大小、面数(如果页面有)、许可和署名文字、适合放在哪里。按"最值得用"排序,10–20 条。写到 result.md。不要下载到项目目录,不要启动浏览器或 Blender。
