# 只读复审:修理铺故事第二版(请苛刻,和上一轮对比)

背景:新游戏(three.js WebGPU 网页短体验)。目的是**宣传 Tripo 生成的 3D 模型**,同时要打动人。拆迁区关了门的家电修理铺,黄昏;屋里每件旧物都是 Tripo 生成的原始网格。机器人是老师傅用旧家电拼的帮手,背对街坐着、面朝店里。

上一轮(4/10、4/10)指出的问题与这一版的改法:
- 镜头特写像"融化的黄圈" → 镜头改成真正的八叶光圈,睁眼时光圈打开(detail-lens-half-open.jpg、story-07)。
- 孩子和机器人的关系没建立 → 环视时先在门边小凳上看到她小时候坐着看书、晃腿的影子(detail-sitting-girl.jpg、story-13);高潮时机器人的眼睛收成一条**水平仪的光线**,一年一年升到她头顶,铅笔就画在光线上(story-15/16/18):它当年就是这样给她量身高的。
- 回到从前像手电验货 → 光束里改成均匀的"另一种光",旧物不再是聚光灯下的一圈;
- "按住"读不清 → 字放大加亮;第一次失败时镜头抖一下、继电器咔哒一声。
- 结尾字幕删掉"灯灭了,门还是那么高",只留"刻度停在十一岁。";
- 机器人近景加了面光,黄昏的街更亮,台灯的光晕收紧;进门时多停一下工作台上的收音机。
- 没改的:模型本身的瑕疵(机器人头顶提手、台灯罩边、凳面、风扇网罩)要重新生成,这一轮不能做;电视节目画面要等素材中台恢复连接。
