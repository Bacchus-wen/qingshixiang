# 只读评审:店里"现在落败、回忆完好",第 3 轮(房间本身、地上的东西、倒下的台扇、摆钟侧面、性能)

背景:第 1、2 轮见 `.agent-tasks/judge-decay-1.md`、`judge-decay-2.md` 和各自的 `result.md`(7.5 → 8.2)。第 2 轮的必改项(背朝外的收音机和台扇)已在上一版改好。用户这次说"我觉得可以继续优化",我列的计划是:房间本身也分现在和回忆;有东西在"现在"倒在地上;修掉摆钟侧面多余的表盘;把多出来的耗时降下来。

这一轮做了什么(`src/systems/shop/decay.js`、`index.js`、`lod.js`、`src/materials/memory.js`):
1. 房间本身:地面在"现在"积灰成片;墙面从天花板往下、从地面往上有水渍;天花板有水渍;屋里的海报褪色发黄。光束照到的地方逐像素回到原样。
2. 地上的东西(只在"现在"):沿墙落的墙皮 140 片(边缘不规则),发黄的碎纸 18 片,纸箱上那台电视前面的碎玻璃 34 片。碎玻璃每片 3 到 5 条直边、角度随机,灰扑扑的,边缘稍亮、表面有光泽能反光。上一版的碎玻璃是黑色正三角,像彩纸屑。
3. 倒下的台扇:门边纸箱上的那台台扇,残破版侧躺在纸箱旁的空地上,底座立着,网罩着地;完好版还站在纸箱上,只在光束里出现。注意:故事里机器人的头最多转约 66 度,光束照不到那个角落,所以这是只属于"现在"的细节。上一版倒下的台扇和纸箱穿插,已挪开(包围盒不再重叠)。
4. 摆钟:完好版生成时侧板上多了一个表盘(残破版没有)。现在在侧板上表盘那一段高度,不是红褐色木头的像素(按色相判断:奶白的盘面、黑色数字、铜圈)都换成带竖纹的深色木头,那里的光照法线压平,表盘的浮雕不再显出来。第一次只压暗亮像素,数字和圈还在画出表盘。
5. 性能(画面不变):
   - 光束边缘的颗粒噪声只在边缘附近计算(其他地方结果本来就是 0 或 1,所有用到这个遮罩的材质都受益);
   - 积灰、水渍、碎片轮廓改为读一张 512×512 的平铺噪声贴图,不再逐像素算三维噪声;
   - 完好版只在光束可能照到它时才画(按包围球和光束锥加余量判断,渲染前才判断)。随机 600 个光束方向、11400 次检查:光束可能照到却被藏起来的 0 次;不画的占 86%。
   - 同一固定镜头交替测 4 轮(每帧等显卡做完):没有落败层的 v30 18.9 毫秒,这一版 20.3 毫秒,一共多 1.4 毫秒;其中残破孪生约 0.1、房间/蛛网/碎片约 0.6、模型的落败材质约 0.7。优化前(加了房间但没优化)多约 2.0 毫秒,上一版(没有房间)多 1.5 到 1.7 毫秒。
6. 完整故事跑一遍,27 个关键画面,没有报错。
