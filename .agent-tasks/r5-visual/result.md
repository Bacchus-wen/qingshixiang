先读上轮意见、当前报告和这批新截图，只对照画面，不改文件。上轮意见和报告对上了。接着看全程试玩和这几张特写，核对门、结尾和新增的猫、照相馆。静帧里门和闪电还有几处对不上。我裁开关键区域再核对，避免把光斑和刻度看错。激光没收到门框上，近景里仍是孩子头顶一条很粗的横带，拖到街对面的积水里，倒影连成一片。

门廊灯和近景都有了，五岁到十岁能读，可六道几乎一样亮，「小宁」叠在「五岁」上；试玩抽到的那格，孩子仍是门口正中一个发白的全身。

空拍有了，孩子消失后有一格门口没人、灯还亮，但这格读不出「十一岁」，抽帧的下一格已经回到有人的街，灯闪不闪也看不出。

结尾做到了：试玩表先是一格纯黑，再出「刻度停在十一岁。」和「灯灭了，门还是那么高。」，字在全黑上，没有「新游戏 · 2026」。光圈半开这张，叶片和多边形光孔都在。

现在最出戏的五处：

1. 闪电。街尽头正对镜头一块均匀灰矩形还在，墙和近处积水上还有几块方片，整条街被抬成中灰。常态已经近黑，这一闪没守住。
2. 门上的孩子。远景是发白纸片人，近景后脑一块发光的六边形，轮廓光粗得像贴纸，刻度是一排一样粗的亮条。
3. 记忆里的人还是浅色低模。照相馆一家人和撑伞的人身体是填实的，「光明照相」屋顶上另有一块纯白几何牌，楼面还有几块纸白窗。
4. 亮处的雨是同样粗、同样疏的实线，近处不虚，从孩子身上切过去。
5. 猫是一块光滑的泥塑，耳朵两根尖刺，脚边水坑把墙和猫照得像镜子。

只剩两小时，按收益：

1. 把门做准。孩子改成黑底细轮廓，拿掉后脑的六边形，半个身子让门框挡住；激光缩成门框上当年那一截细线；只亮「十一岁」，其余退回铅笔灰，「小宁」和「五岁」错开；空拍的机位推到能读出这行字。都是灯光、材质和机位。
2. 闪电那块灰矩形，连同墙上和水面上的方片，移出画面；闪电压暗，只留楼的轮廓和湿地反光。
3. 记忆里的人压成暗剪影，只留一圈琥珀边；屋顶的白牌和纸白窗压暗，光斑边缘弄缺。
