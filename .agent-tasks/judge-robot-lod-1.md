# 只读评审:机器人第一次靠近时"材质闪变"的修复

用户反馈:"那个机器人在第一次靠近时,材质突然闪变了"。

我查到的原因:
- 每个模型有 L0–L3 四级精细度,网页上最细到 L1,开场每个模型从最粗的 L3 开始,镜头靠近时再换细一级(换级是 0.35 秒的抖动交叉淡入)。
- 用实时逐帧记录复现:开场约 7 秒(镜头从街上进到店门口),机器人从 L3 换到 L2;约 11 秒换到 L1。
- 机器人的 L3 和 L2 编码不同:L3 的颜色和粗糙度贴图是 ETC1S(损失大),法线贴图是 PNG;L2、L1 三张都是 UASTC。所以 L3 → L2 不只是变清楚:背板的明暗、线缆的粗细、管接头的细节都变了。同一个固定机位下对比见 `docs/judge/robot-lod-1/old-first-change.png`(1:1 放大)和 `old-first-change-wide.jpg`(整帧)。
- L2 → L1 在同一机位下几乎看不出变化,见 `remaining-change.png`(左 L2、中间淡入中、右 L1,1:1)。

修复(`src/systems/shop/lod.js`、`src/systems/shop/index.js`):
- 每个模型可以指定"最粗用到哪一级"。机器人和它身下的凳子设为 L2:加载画面里直接加载 L2,开场就显示 L2,永远不用 L3。
- 实测(同样的开场逐帧记录):机器人整个开场只换级一次(约 11 秒 L2 → L1),凳子不换级;没有新的显卡程序编译,没有跳过的绘制。
- 代价:加载多 9.6 MB(机器人 L2)+ 1.1 MB(凳子 L2)。加载画面结束时间 3.85 秒 → 4.41 秒;开场帧率不变。完整走一遍故事没有报错。
- 没有改的:其他模型的 L3 也是同样的编码,但它们在画面里小,我没有动。
