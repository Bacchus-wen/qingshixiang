# w17:远处路口开过的那辆车的声音

Claude 加了 `src/systems/street/passing.js`:大约每 70–115 秒,一辆真实的(现在的)车从远处路口横穿过去
(路口在 z=-42,车沿 x 从 -58 开到 +58 或反向,速度 9.5 m/s,约 12 秒)。
它每帧写 `ctx.world.passingCar = { x, z, k }`,k 是 0..1 的存在感(两端淡入淡出,不在时为 0)。
调试:`?passcar` 让它 2 秒后出现,之后每 6 秒一次。

请在音景里加上它的声音(只改 `src/systems/audio/**`):
- 湿路面的轮胎嘶声 + 很低的发动机声,距离远(机器人在 z≈-10,离路口 30 多米),所以要低通、混响多、音量小;
  按 x 做立体声声像,按到听者的距离做衰减,经过路口正中时最近最响。可以用合成噪声,也可以拿 city_far_loop 的一段做颗粒;不要新的音频文件。
- 记忆光锥打开时它照常存在(它属于现在),但被现有的记忆低通一起压住。
- 更新 verify.mjs 覆盖:k=0 时静音、经过时声像从一侧到另一侧、不重复触发。
- 不启动浏览器、Vite、Blender。
