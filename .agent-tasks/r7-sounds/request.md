# 任务:找可用的真实环境录音(只读,可联网)

项目 新游戏(读 AGENTS.md、docs/research-relocation-grok.md 第 3 段):雨夜空巷,非商用网页作品。目前声音全是程序合成,用户希望加入真实录音增强质感,可以网上找。
请找 8 到 12 条**可以合法用于非商用网页作品**、**可直接下载**的录音,类别:近处雨打铁皮卷帘、雨落在积水/石板、屋檐滴水进桶、空巷远处城市低频底噪、远雷、风穿过窄巷、远处一只狗、老式收音机杂音、雨中的机械伺服或继电器(可选)。
每条给:标题、页面链接、**直接下载链接**(mp3/ogg/wav,能用 curl 下载的)、时长、许可证原文名称(CC0 / Pixabay License / CC BY 4.0 需署名等)、是否需要署名及署名格式、为什么适合。优先 CC0 和不需要登录即可下载的来源(如 Pixabay、Freesound 的公开预览、BBC RemArc 非商用、Sonniss GDC 免费包中的单文件等),逐条核实许可页面。
只读,可联网,不得调用付费生成,不要修改项目文件。中文,列表形式,1200 字以内。
