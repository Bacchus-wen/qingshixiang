# 只读评审:第一幕到第二幕的故障转场,第 3 轮(全新评委,请苛刻)

背景:新游戏 是一段 three.js WebGPU 网页实时体验,目的是宣传 Tripo 生成的 3D 模型,同时要打动人。故事:拆迁区一间关了门的家电修理铺,黄昏;店里的旧物和小机器人都是 Tripo 生成的原始网格。机器人的眼睛像一台记忆投影机,光照到哪里,哪里就回到从前。

第一幕结尾,它背对店门、面朝工作台;街对面的电器行"新興電器"传来同一支曲子,第二幕它要面朝街。用户否决了动画转身(钢铁身体被拉伸),要求"直接故障特效转场"。

第 1 轮 5/10,第 2 轮 7/10,意见见 `docs/judge/transition-1/`、`docs/judge/transition-2/`,以及 `.agent-tasks/judge-transition-{1,2}/result.md`。第 3 轮按第 2 轮意见做了以下改动:
- 剪后机位从偏 25 度改到 35 度,能看到镜头侧边,头在画面里的位置和剪前相差不到画宽的 1%。剪后它的视线向左偏约 24 度,正对电器行,光束落点落在画面左侧约 13% 处,电器行回到从前,整个出现在画面左侧。
- 视线一直停在电器行,直到观众移动鼠标才交还控制;镜头停约 1 秒后,用 1.6 秒移到第二幕主机位,这时电器行在画面中央。
- 第一次眼睛变暗改为 0.50–0.66 秒,光束和落点降到原来的 25%。
- 声音只在 1.18 秒撕裂开始时响一声爆音,加低沉的嗡声,前两次小故障不发声。
- 操作提示改为剪后 2.9 秒出现,在运镜结束之后。
- 平时行错位上限从 0.8% 降到 0.4%;强撕裂只出现在一两条窄带(画高约 2.5%)里,峰值约 0.09 秒。
- 雪花带横向分成 50 段,一半随机留空,透明度不超过 0.25。
