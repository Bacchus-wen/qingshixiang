# 只读盲评:同一张输入图生成的三台老电视 3D 模型,哪个好

只看 `docs/tripo-compare/blind-tv/` 这个文件夹。不要看其他图、清单、日志、代码或生成记录(那里写着来源)。
- `tv-input.png`:输入图,三个版本都由它生成;
- `tv-closeups.jpg`:P、Q、R,同机位、同中性灯光的近景(控制面板一侧);
- `tv-views.jpg`:P、Q、R,四个角度(前斜、侧面、后斜、俯视)。

用途:写实电影感网页场景(一间九十年代家电修理铺),这台电视出现多次,货架上有的正面朝外、有的背面朝外,还有一台放在纸箱上做产品近景(会看到旋钮、刻度、格栅、木壳)。

要你做:
1. 每个版本按四项各打 1–10 分:和输入图的一致性;几何细节与结构是否正确(旋钮、刻度盘、格栅、屏框、背面结构);贴图清晰度与材质;近景瑕疵(软塌、融化、粘连、乱码)。再给总排名。
2. 每个版本写一句最大的优点、一句最大的问题,并指出位置。
3. 如果只能选一个用在这个场景里(既有近景正面,也有背面朝外),选哪个,为什么。

权限:只读,不联网,不调用付费生成,不启动浏览器、Blender、Vite 或长时间进程,不改文件。
交回:中文,600 字以内,直接在回复里。
