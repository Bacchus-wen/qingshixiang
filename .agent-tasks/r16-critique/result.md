对照 `docs/targets/present.jpg`、`robot.jpg`、`memory.jpg`，以及 `docs/review3/ref-cyber-08s.jpg`、`ref-cyber-40s.jpg`。下面只评六张实时帧。目标图和参考帧是尺子。

像素是 1280×720 上每隔 4 像素量的。亮度是 Rec.709。

总判：现在是一张欠曝的黑场，中间一块路灯圆盘。记忆把整条街涂成中灰的糖果色，街上没有人。机器人近景是均匀灰塑料，眼睛是一颗橙斑。参考和目标赢在三件事：阴影里还能看见材料，颜色只占很小的面积，地上是拉长的倒影。

## 1. 每张图

### now-street.png（对照 present.jpg）

1. 阴影是死的。全帧 42% 的像素亮度低于 18，平均 (22, 22, 29)。左侧墙面约 (6, 10, 14)。目标图里卷帘、墙皮、三轮车都落在中灰，雨夜仍然能读出材料。
   改法：`src/systems/street/details.js` 的半球光从 `intensity 0.1` 提到 `0.35`，天空色 `#6a7388`，地面色 `#2a2622`。墙的粗糙度维持在 0.7 以上，靠这点环境光把砖和卷帘从黑里捞出来。`PostFX` 的 `exposure` 已经是 `0.95`，再抬曝光只会把那块路灯圆盘烤白。

2. 路灯是地面上的一块硬圆盘，没有光柱。竖向中带：y=0.45 亮度 35，y=0.65 亮度 98、峰值 241，y=0.88 回到 22。灯在 `details.js`：`SpotLight(0xffc690, 650, 26, 0.62, 0.7, 2)`，位置在路灯头 `(halfRoad, 6.8, -3)`。目标图的钠灯是灯头、雨里的光柱、碎水坑里的暖倒影，三件一起出现。
   改法：强度 `650 → 160`，`decay 2 → 1`，`angle 0.62 → 0.95`，`penumbra 0.7 → 0.35`。给这盏灯单独一个跟着灯头移动的体积盒，密度约 `0.8`，只散射这一盏（`atmo.volume(..., onlyLights)`）。现在体积光只挂在眼睛上，盒子钉死在 `(0.3, 3, -14)`。

3. 路面是一整张镜子，活着的招牌还是饱和色。`groundRoad` 的 `coverage: 0.75`，水坑粗糙度在 `wet.js` 落到 `0.015`。近处路面饱和度 0.47，来自紫和粉的倒影。存活招牌是每侧 4 块 blade（`layout.js`），现在态颜色是 `mix(灰, tint, 0.8)` 再乘 `masks.g * 2.6`（`neon/materials.js`）。目标图只有两块又小又残的灯，其余是钠灯和湿沥青。
   改法：每侧存活改成 1。`faded` 的混色系数 `0.8 → 0.2`。`memory.strength == 0` 时把 `PostFX` 的 `saturation` 从 `1.12` 降到 `0.2`，`hueKeep` 从 `0.45` 降到 `0.1`。`coverage 0.75 → 0.32`。水坑粗糙度下限 `0.015 → 0.08`。

### past-street.png（对照 memory.jpg 的街，和两张参考帧）

1. 没有黑。平均 (101, 79, 76)，亮度低于 18 的像素只有 1%。参考帧里车身、衣服、巷子尽头是黑的，霓虹是小面积高光。墙被 16 盏解析霓虹整个涂满。`neonlight.js` 用 `dot(N,L)+0.35` 做包裹，范围 `7 + 宽度*1.6` 米，强度 `0.9 + 面积*0.55`。
   改法：包裹改成 `max(dot(N,L), 0)`。范围改成 `3.2`。强度改成 `0.3 + 面积*0.12`。混凝土保持自己的颜色。招牌的颜色只留在灯箱和倒影里。

2. 街是空的。人最多 16 个，走在 `x = ±4.2`、`z = -7 到 -35` 的窄环上（`ghosts/index.js`，`TURN_RADIUS 0.38`）。车 `COUNT = 4`（`traffic/index.js`）。参考 8 秒有货车、面包车和行人。40 秒右侧是一排撑伞的人。`memory.jpg` 的人行道是市集。
   改法：人每侧 24，共 48。路线拉到 `z = -4 到 -70`，走在真实步道上。车改成 12 辆：8 辆停在路边，4 辆行驶。车身反照率 `0.02`，只有灯片发光，头灯强度 6，尾灯 3。

3. 招牌是一块发光平面。`geometry.js` 用 `PlaneGeometry` 贴图集，`TUBE_INTENSITY = 5`，光晕 `halo * 0.22` 把板心也点亮。参考里的灯有盒子、支架和玻璃管的厚度。
   改法：`halo` 系数 `0.22 → 0.04`。柜体深度加到 `0.18`，柜体反照率压到 `0.02`。笔画改成沿字形中线的 `TubeGeometry`，半径 `0.015`。平面贴图没有法线，玻璃高光出不来。

### past-low.png（贴地）

1. 前景是高频彩纸屑。整帧亮度挤在 75 到 120。前景 y=0.88 亮度 78、峰值 169。半分辨率 SSR 打在很碎的法线上：`PostFX.js` 里 `resolutionScale = 0.5`、`quality = 0.5`、`thickness = 0.15`。`wet.js` 的涟漪是 `sin(距离 * 42)`，幅度 `0.35`。水坑粗糙度 `0.015`。
   改法：这条路是平面。倒影改用斜投影平面反射，半分辨率，再按粗糙度模糊。涟漪频率 `42 → 14`，幅度 `0.35 → 0.06`。粗糙度下限 `0.015 → 0.06`。SSR 从路面上拿掉。

2. 路灯在贴地机位变成一条亮横带，把倒影切断。同一盏灯，`intensity 650`、`decay 2`。
   改法：强度和衰减按 now-street 第 2 条改。记忆全开时这盏灯再乘 `0.4`，招牌倒影做主光。

3. 地上另有一层加法色饼。`neon-ground-spill` 铺在路面上，颜色 `spill * 0.55`，透明度按半径平方衰减（`neon/materials.js`）。贴地看是一块块色。
   改法：这层透明度乘 `0`，停止合并 `pools`。路面颜色只来自平面反射和很弱的解析光。

### past-high.png（俯视）

1. 俯视把招牌拆穿了。大字是描边平面。侧向灯条 `accent` 强度 `3.2`（`geometry.js`），看起来像界面描边。柜体在这个角度几乎没有厚度。
   改法：和 past-street 第 3 条同一套管子和深柜。侧条强度 `3.2 → 0.5`。

2. 路面是色块。俯视时 SSR 的射线贴着地面滑，`thickness 0.15` 打不中立着的招牌，`maxDistance 100` 也补不上。加法光池在这个角度就是椭圆。画面下半亮度约 100，和墙差不多。
   改法：平面反射会映出立面。删掉光池。反射强度乘 `smoothstep(0.25, 0.02, roughness)`，干的地方保持沥青。

3. 这个角度最该看见人和车，画面里没有。16 个人从这个高度是几个像素。店内没有暖光，墙被霓虹整个染绿、染粉。参考 40 秒的店是暖的盒子，霓虹只在门口那一条。
   改法：人数按 past-street 第 2 条。每个 `shopOpening` 加一张内景四边形，色温 2800K，发光强度 `2`，尺寸不超过门洞。内景不吃 `neonIrradiance`。

### robot-wide.png（对照 robot.jpg）

1. 整个角落是一块品红。平均 (26, 20, 30)，饱和度 0.24。主光是头顶那块招牌。目标图是白陶瓷加锈，远处是冷街，地上的暖灯和冷灯倒影是分开的。
   改法：机器人 4 米内把 `neonGain` 乘 `0.25`。从右后方加一盏聚光，颜色 `#ffb46a`，强度 `40`，`angle 0.6`，只照上表面。半球光按 now-street 那条抬起来，砖回到棕灰。

2. 身体是摆在台阶上的光滑模型，和地面没有压上的关系。目标图的腿和脚陷在水里，接缝是暗的。陶瓷 `metalness` 是 0。污渍是世界空间噪声（`materials.js` 的 `grime` 和 `tears`），噪声不进凹槽，远看是一个灰团。
   改法：壳加 `clearcoat 0.4`、`clearcoatRoughness 0.18`，只在 `normalWorld.y > 0.5` 的面。再乘一张腔体 AO，半径约 8 厘米，缝和接地点压到 0.4。没有 AO 贴图就先开屏幕空间 AO，半径 `0.35`。

3. 姿态和景别是产品照。`shots.js` 的 `robot-wide` 从 `(1.6, 1.3, -9.5)` 看向 `(-4.4, 0.7, -13.6)`，fov 40。人缩在墙洞中央，前景还有一把破伞挡住下半。目标是靠着卷帘，一条腿伸出去，猫在旁边。
   改法：fov 改 `28`，机位拉到离身体约 4 米。根骨骼再靠墙 `0.3` 米，骨盆转一个靠墙的角度，一条腿伸直。猫放到小腿外侧。破伞移出这张机位。

### robot-close.png（对照 robot.jpg 的头部和壳体）

1. 头和肩是一块灰。这块区域平均 (65, 59, 63)，饱和度 0.12。`shell_ceramic` 底色是 `(0.34, 0.32, 0.28)`。锈用频率 45 的噪声铺在整个表面上，混合系数 0.75。近看像均匀塑料。
   改法：陶瓷底色改成 `(0.62, 0.58, 0.52)`。锈和油只乘在腔体 AO 暗、且 `abs(normalWorld.y) < 0.25` 的地方。世界噪声的混合从 `0.75` 降到 `0.15`，只留细划痕。

2. 眼睛是一颗橙斑，虹膜和玻璃都没了。`eye_core` 的发光是 `eyeGlow² * 7`。这一带峰值亮度 232，旁边的壳大约 60。bloom 阈值 `0.9`，晕开之后更像一颗灯。
   改法：`mul(7)` 改成 `mul(1.3)`。玻璃 `opacity 0.35 → 0.6`。虹膜环自己的发光不超过 `0.35`。`bloomThreshold` 从 `0.9` 提到 `1.6`，只有灯芯过阈值。

3. 胸口破口是空的黑，背景卷帘是死的。卷帘区域约 (18, 7, 20)。`bokeh` 默认是 0，特写和远景一样清楚，卷帘的重复纹理和机器人抢。
   改法：破口里放已经有的 `frame_dark` 管子。这张镜头设 `bokeh = 2`，`focus` 锁在眼睛，`focalRange = 0.4`。卷帘靠那盏钠灯补一点。

## 2. 全局 Top 10

按改完之后六张里能好多少来排。

1. 路面改成斜投影平面反射。删掉 `neon-ground-spill`。涟漪频率降到 14，幅度降到 0.06。past-low 的彩纸屑、past-high 的色饼、now 的整张镜子一起解决。SSR 留着也照不好贴地和俯视。
2. 霓虹解析光收短。取消包裹，范围 3.2 米，强度大约砍到现在的三分之一。墙回到混凝土，画面里重新出现黑。这是 past-street 发灰的原因。
3. 现在态把阴影捞起来，路灯从圆盘改成带体积的钠灯。半球光 0.35，路灯强度 160、衰减 1。now-street 现在 42% 是死黑。
4. 记忆态的人加到 48，车加到 12，车身保持深色。空街是和 `memory.jpg`、两张参考帧最大的差别。着色改不动这件事。
5. 招牌改成细管加深柜。光晕系数降到 0.04，侧条降到 0.5。俯视才不再像一块界面。
6. 体积光跟着灯走。眼睛的锥和路灯的柱都用「灯在体积层里」的做法。现在的 `beamVol` 钉在固定盒子里，密度只有 `0.35 * 睁眼`。`memory.jpg` 的主角是那根琥珀锥。我们的记忆三张里它不存在。
7. 机器人壳体：底色抬到灰白，乘腔体 AO，朝上面加 clearcoat 0.4。眼睛发光从 ×7 降到 ×1.3。近景现在是饱和度 0.12 的灰。
8. 雨只在被照到的地方画出来。`rain/index.js` 的底色有 `vec3(0.65, 0.72, 0.8) * 0.05`，透明度还有 `0.56`，黑夜里也是一层划线。底色乘光照亮度，暗处透明度归零。再用来自屋顶的高度决定雨停在哪里。
9. bloom 阈值提到 1.6。机器人特写打开景深，`bokeh 2`，焦点在眼睛。灯芯可以开花，壳和卷帘保持清楚。
10. 每个店门一张 2800K 的内景，强度 2。记忆街现在是灯牌走廊。参考帧的暖来自店里面。

## 3. X 上能直接用的做法

1. 湿路用平面反射。Anderson Mancini 和 Sunag 的浏览器雨夜城 Threejs-Punk，X 上最近还在转。郝的帖子写了雨、霓虹、车，并给了地址：https://x.com/haolv511482/status/2110893577878536227 ，演示在 https://www.threejspunk.com/ 。Anderson 自己说这是 Three.js + WebGPU + 大量后期：https://x.com/Andersonmancini/status/2110839873531723906 。源码里写明湿地面是半分辨率斜投影平面反射，SSR 已经拿掉：https://github.com/ektogamat/threejs-conference （`src/world/ground/createGround.js`，说明在 `docs/techniques/wet-ground.md`）。同一类原生移植：https://github.com/0beqz/vanilla-threejs-meshreflectormaterial-example 。对应第 1 条。

2. SSR 要留就得去噪。@SeeOn__ 2026-07-02 的厨房场景写明用了 @0beqz 的 SSR denoiser：https://x.com/SeeOn__/status/2072565594310984181 。仓库是 https://github.com/0beqz/realism-effects ，里面同时有 SSGI 和 AO，AO 来自 N8programs。AO 用来解决第 7 条的壳体接缝和脚底悬空。我们现在的 SSR 是半分辨率、没有去噪，再乘频率 42 的涟漪，所以是彩纸屑。

3. 体积光跟着聚光灯走，并用和 TRAA 相同的抖动把它混干净。官方例子：https://threejs.org/examples/webgpu_volume_lighting.html ，源码 https://github.com/mrdoob/three.js/blob/dev/examples/webgpu_volume_lighting.html 。TRAA 同步版的合并记录：https://github.com/mrdoob/three.js/pull/32953 。Sunag 在 X 上直接讲了 `webgpu_volume_lighting_traa`：https://x.com/sea3dformat/status/2083026461082972575 。对应第 6 条，也对应 now-street 那块没有光柱的路灯圆盘。

4. 雨打到屋顶就停，暗处不画。还是 Threejs-Punk 那套。顶视高度贴图决定落点，说明在 https://github.com/ektogamat/threejs-conference 的 `docs/techniques/collision-rain.md`。我们的雨是一个 26×16×64 米的盒子，再加一个不随光照归零的透明度，所以六张图都有一层均匀划线。对应第 8 条。
