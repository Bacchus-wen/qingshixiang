**A．剧情方案**

三案均约4—6分钟：发现与睁眼约45秒，记忆约2分钟，其余留给寻找、停顿和结尾。光照物体后触发片段；松手暂停，重新照亮继续。声音以雨、机械、脚步与敲击表达，不依赖对白。

**方案一：《借来的零件》——一条街共同修好的机器人**

机器人是街区公共维修员；玩家不设身份。工厂停产后，居民逐渐迁走，暗示是空置店铺、搬运车和不断缩短的营业时间。它的残破身体，保存着居民反过来修理它的痕迹。

| 触发物 | 记忆画面 | 时长／情绪 |
|---|---|---|
| 歪斜的店门铃 | 它修好门铃，店主反复推门，故意让它多响几声 | 20秒／轻快 |
| 锈蚀的自行车轮 | 它扶住车座；骑车的人已经骑远，它仍保持扶着的姿势 | 22秒／笨拙温柔 |
| 裂开的搪瓷碗 | 它手腕失灵，碗摔碎；居民蹲下捡碎片，先扶住它的手 | 24秒／羞怯、被接纳 |
| 缝纫机踏板 | 店主把踏板连杆装进它的膝盖；几个人扶它试走 | 26秒／关系倒转 |
| 一截铜门把手 | 最后一间店搬空，店主卸下门把手，替它补好眼睛支架 | 28秒／告别而非抛弃 |
| 地上的维修工具盒 | 搬运车留着空位；它起身时膝盖卡死，众人返回，合力抬起它 | 25秒／希望被截断 |

结尾：最后一段损坏，无法知道那次搬运为何未成。眼光熄灭，现实中的膝盖轻响，声音正是缝纫机的节拍；机器人用借来的零件，把自己从积水里挪高一点。它没有等待某位主人，仍在照顾被大家修好的身体。

**方案二：《这条线经过我家》——帮助离开，也参与抹去**

机器人是迁城测绘员；玩家通过它的眼睛看。城市因地面沉降被撤空，水位线与倾斜门框提供暗示。它曾准确地完成工作，却无法把“安全撤离”与“失去家”分开。

| 触发物 | 记忆画面 | 时长／情绪 |
|---|---|---|
| 墙上的红色测量钉 | 它画线，一只手把晾晒的床单挪开 | 20秒／日常被打断 |
| 门框上的身高刻痕 | 测量线盖过刻痕，住户用湿布擦出其中一小段 | 25秒／抵触 |
| 路口金属坡板 | 它拆下自己的护甲，铺过裂缝，让轮椅通过 | 25秒／职责的善意 |
| 被卸下的门牌 | 搬家的人想取走门牌，它扶稳梯子；墙上留下浅色轮廓 | 25秒／共同参与离别 |
| 它掌下的断墙砖 | 最后一夜，它复制那组身高刻痕，刻进自己的前臂 | 30秒／迟来的理解 |

结尾：光束逐渐无法维持，玩家松手后，机械臂转向雨光，现实里仍能看见刻痕。它没有保存整座城市，只保存了测量表里没有的一小段长度。

**方案三：《掌声慢半拍》——不把快乐解释成灾难的伏笔**

机器人是街头小剧场的节拍与灯光助手；玩家是无身份的观看者。城市荒废原因留白，只通过逐次减少的椅子、封闭的交通入口和撤走的设备暗示长期衰退。

| 触发物 | 记忆画面 | 时长／情绪 |
|---|---|---|
| 翻倒的折叠椅 | 观众挪椅避雨，最后挤成一个歪斜半圆 | 20秒／亲近 |
| 排水管上的凹痕 | 演员忘带鼓，拿管道打节拍；机器人认真跟上 | 25秒／即兴快乐 |
| 打结的幕布 | 幕布卡住，演员从底下钻出，把事故演成节目 | 25秒／放松 |
| 裂开的灯罩 | 断电后，观众轮流举灯，机器人第一次成为被照亮的演员 | 28秒／意外被看见 |
| 门口的小铜铃 | 最后一场只有两名观众；演完后四个人互相鞠躬，谁也不肯先停 | 30秒／可笑又不舍 |

结尾：记忆消散，雨滴敲击管道，偶然形成旧节奏。玩家再次短按，机器人用剩下的手指补上迟到的一拍；没有复活的人群，也不判定这是最后一次。

**推荐方案二。**“测量线覆盖身高线”能用一个画面建立矛盾，前臂刻痕又能在断电后留下真实证据。光锥天然承担寻找与辨认，松手也成为结尾动作。资产集中于墙、门框、坡板和手臂，少量人物剪影即可成立；相比第一案，较少依赖解释机器人为何留下，相比第三案，更紧密连接废城与机械眼。

**B．核心技术风险审查**

已核对本地 three.js 0.186.1 源码；以下是设计审查，尚未做运行验证。

1. **像素成本**：`mix`不保证跳过另一套纹理采样，雨、噪声和后处理还会叠加。共享光锥节点与uniform，限制贴图、实例化人群；降分辨率，分别测两后端帧耗时。
2. **几何差异**：材质不能凭空升起卷帘门或补齐车壳。形变且拓扑相同的用顶点动画；拓扑不同的保留两套局部网格，以互补光锥遮罩裁切，并同步深度与阴影。
3. **穿墙显影**：角度判定没有遮挡。统一世界坐标，使用半锥角、归一化朝向及近远距离；需遮挡时增加眼位深度图比较，原型可先限制可见区域。
4. **光照不一致**：自发光不会自动照亮邻物，历史实体也可能留下幽灵阴影。少量代理灯补光；历史人群先不投影，必要投影必须复用显隐与形变逻辑。
5. **透明排序**：人物、雨、光束交叠会出错，`depthWrite=false`无法根治。人物优先不透明抖动裁切；光束少层加法混合、保留深度测试，控制雨幕过绘。
6. **回退差异**：r186提供WebGL2后端，但不能保证所有节点功能等价。核心使用两后端共有节点，避免依赖专用计算功能；用`forceWebGL:true`检查光锥边界、裁切、阴影及性能，初始化失败另给静态提示。
