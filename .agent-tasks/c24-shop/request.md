# 只读复审(第二轮):修理铺 模型 + 摆放

## 背景
新游戏(three.js 0.186 WebGPU + TSL)。1990 年代中国老街家电修理铺 + 旧家电拼成的机器人,目的:展示 Tripo 生成的 3D 模型质量(近看经得起、摆放真实不悬空不穿插、页面轻、别人设备流畅)。当前只做模型和摆放,灯光以后再做。Tripo API 余额为 0,不能生成新模型。

## 上一轮你提的问题(c22-shop)和我做了什么
- 落地:改为"下落检测",用精确(顶点级)包围盒;从物体最低一圈顶点向下投射,取最小间隙;没有命中会警告。桌下物件可指定只落在地面(on: floor)。
- 审计 `tools/shop-audit.mjs`:精确包围盒;货架层间净高/立柱/前后沿检查;房间墙/天花/前墙检查;两物体框重叠后再做顶点级"内外判定"(射线奇偶),分 CLIP(真穿插)与 NEAR(只是挨得近)。当前 96 件:0 悬空 0 穿插,2 条 NEAR。
- 加载与资源:每个 GLB 只解析一次,摆放用克隆共享几何/材质/GPU 贴图;房间贴图转 KTX2;模型 meshopt + 分级贴图(小件 512、普通 1K、机器人 2K),模型 31→22 MB;货架合并为每架 3 次绘制,纸箱 2 次;three.js 原来被打包了两份(插件 import 'three',应用 import 'three/webgpu'),已在 vite 里把 'three' 指向 'three/webgpu',开发态加载 6.9→3.2 秒。
- 主角区:工作台与机器人前移 0.7 m,机位收紧到像目标图那样(室内占满画面、柱子招牌被裁、卷帘门压住顶部);机器人旁加了 Tripo 生成的备用躯干和腿,墙上挂备用手臂。
- 其他:机器人去粉色偏色、镜头眼发光、"上海"铬标与"人民电器"铭牌做成几何体;灯管线管、机器人电源线、货架电器垂下的电线;洞洞板加厚度与少量立体工具;货架物件歪放、小件叠放。
