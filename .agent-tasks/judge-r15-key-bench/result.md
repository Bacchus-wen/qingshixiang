2. **光源归属相反。**左上大片橙光主导曝光，收音机像被窗外夕阳照亮，机器人眼睛只是白点。降低左侧光及雾亮度约一半作为起点；让眼灯确实照中裸露电路，形成清楚的局部光斑、遮挡阴影和少量可见光束。

3. **机位过于俯视桌面。**前景桌面占据大量画幅，机器人躯干被底边截断，台钳又隔开两位主角。降低机位、减少俯角，以眼睛和收音机内部为取景中心；将台钳移向近侧边缘，露出手臂与维修位置的关系。

4. **亮暗分配失衡。**收音机顶边、内部及桌面一起发亮，右下机器人却糊成黑团。压低桌面与顶边亮度，给机器人胸腹、手部增加弱而宽的反射补光；最高亮度留给眼灯与被唤醒的部件。

5. **收音机结构仍有生成感。**内部细杆、线束、右侧扬声器支架出现粘连和软化，开盖机构不清楚。逐件清理轮廓，补出明确铰链、板件厚度及线束连接；无法整理的内部网格应重做或重新生成。

6. **机器人头壳像锈木箱。**右侧大面与顶面满铺高对比橙褐纹理，金属、漆层、锈斑难区分。保留大片完整漆面，锈集中于接缝和破口；把手、镜筒、紧固件分别设置粗糙度，清理肩部融成团的结构。

7. **桌面像粗砂石。**木纹被均匀颗粒和强反光淹没。降低法线与锐化强度，明确沿板长方向的木纹；油污、划痕只集中在维修区，减少全表面等量做旧。
