# 只读评审:店里"现在落败、回忆完好"的材质层,第 1 轮

背景:用户想让店里的物件也有"现在残破/回忆完好"的对比,选了"材质层 + 3–4 件主角做真残破模型"。残破模型正在生成(另一个任务),这一轮只看材质层。

做法(`src/systems/shop/decay.js`,接入在 `lod.js` 的 `decorate` 和 `index.js`):
- 光束外的店是"现在":朝上的面积灰(灰色,按两种尺度的世界坐标噪声成片),其他面一层很薄的灰;颜色褪掉 40%、暗 14%;积灰处变哑光,盖住金属光泽。
- 光束照到的地方逐像素回到原样(干净、颜色饱满),用的是和对街照片同一个"记忆遮罩",边缘一样柔和。
- 机器人的角落不加:机器人、它的凳子、工作台、台灯、拆开的收音机、电烙铁、放大镜、搪瓷杯。理由:这是它唯一还在打理的地方。
- 货架隔层的角上和房间顶角挂了蛛网(灰色、断断续续、挂着灰),只在"现在"出现,光束照到就消失。
- `?nodecay` 可以关掉整层做对比。

看图(`docs/judge/decay-1/`):
- `present.jpg`:眼睛闭着(全是"现在"),左边原来,右边加了材质层。
- `beam.jpg`:光束停在纸箱上那台电视上,左边原来,右边加了材质层。
- `cobwebs.jpg`:两处蛛网近看(故事里不会这么近)。

请回答:
1. "现在"读起来像落败了吗?和光束里的"回忆"对比够不够?强度是太弱、合适还是过头(会不会像蒙了一层灰滤镜而不是积灰)?
2. 机器人角落保持干净,是加分还是显得不一致?
3. 蛛网像不像,位置合不合理?
4. 必须改的写清位置、原因和参数;可以不改的也说明。
