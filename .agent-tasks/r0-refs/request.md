# 任务:参考作品调研 + 三个差异化美术方向(只读)

## 背景
项目 新游戏(项目根目录下的 AGENTS.md 和 docs/concept-ruin.md 请先读)是 3 到 8 分钟的网页短体验:荒凉的雨夜废城 + 一台残破的机器人,玩家长按让它的机械眼睁开,光锥照到的地方显出城市的过去。非商用,用 three.js WebGPU + TSL shader + CSS + 无界面 Blender 脚本实现,不用任何付费生成。
用户要求:可以参考下列作品,但风格必须不一样。

## 要做什么
1. 联网查看这些作品的画面和社交媒体帖子,概括每个的视觉签名(色彩、光源、材质、构图、UI、镜头),各 3 到 5 条:
   - Cloudpunk(ION LANDS,2020)和 Nivalis Nights(ION LANDS,2026)
   - xikhar 的 NEON KAIDO:https://github.com/xikhar/cybercity 及其 X 帖子
   - thtbee_ 的 Kestrel K-1 和 STRIX HX-9:https://thtbee.github.io/waggles/
2. 据此列出"我们必须避开的东西"清单。
3. 提出 3 个互相差别明显的美术方向,都要能表现"荒凉、绝境、雨夜",并且能在浏览器里实时做出来。每个方向写:一句话气质、主色和光源(给出具体色值)、材质语言、镜头语言、UI 气质、现实中的灵感来源(电影、摄影师、画家或游戏,写具体作品名)、实现难点。
4. 最后推荐其中一个,说明理由。
